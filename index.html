How it works

A straightforward workflow for spotting scams on screen.

SafeView focuses on the parts of the screen that change most, then checks the visible text against scam signals without sending anything off-device.

01. Capture

Screen OCR

It reads visible text using optimized OCR so it can focus on changed screen regions instead of reprocessing everything.

02. Analysis

Hybrid detection

Detected text is checked through semantic similarity and rule-based scans for suspicious URLs or phone numbers.

03. Response

Overlay + logs

When a threat is confirmed, SafeView can show an overlay, save evidence, and keep a review trail locally.

Security model

Local-first by design.

SafeView performs OCR, URL detection, and semantic matching on the local machine so it stays useful in desktop workflows where scams appear through chats, email previews, browser tabs, and pop-up messages.

Privacy

Text is processed on-device and logs stay local unless you export them yourself.

Tuning

Thresholds, trusted domains, screenshot saving, and launch preferences can be adjusted through configuration and settings.

Operator feedback

False positives can be marked safe and suspicious items can be reported so the tool keeps improving on the same machine.
